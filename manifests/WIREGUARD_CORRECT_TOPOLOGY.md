## 9. Вплив NAT на etcd

На роутерах VRN625 і Syhiv17 у POSTROUTING є **MASQUERADE** для трафіку в wgclt+. Трафік з macmini7 (192.168.2.19) через VRN625 виходить із source IP тунелю VRN625 (192.168.100.6 або 192.168.200.6). Трафік з beelinkeqr5 (192.168.1.19) через Syhiv17 — із source IP тунелю Syhiv17 (192.168.100.2 або 192.168.200.2). Тому etcd бачить ці тунельні IP; для TLS потрібні відповідні **tls-san** або прямі тунелі нод↔Amper без NAT (wg2/wg3), де source залишаються 192.168.2.19 та 192.168.1.19.

Цей файл узгоджений з **FRR_OSPF_CONFIG_EXAMPLES.md** та використовує лише дані з наданих конфігурацій.
